# 브릿지 커피 디지털 메뉴판

손님이 테이블의 QR 코드를 찍으면 휴대폰으로 보게 되는 디지털 메뉴판이에요.
파일 하나(`index.html`)로 만들어서 설치할 것이 없고, 더블클릭만 하면 열려요.

## 주요 기능

- **카테고리 버튼**: 전체 / 커피 / 논커피 / 디저트. 누르면 해당 메뉴만 보여요. 처음에는 `전체`가 선택돼 있어요.
- **사장님 추천 배지**: 지정한 메뉴에 배지를 달고 카드를 살짝 더 눈에 띄게 보여줘요.
- **오늘 품절 표시**: 품절 메뉴는 흐리게 보이고 `오늘 품절` 배지가 떠요.
- **영업시간과 전화 걸기**: 맨 아래에서 영업시간을 보고, 버튼을 누르면 바로 전화를 걸 수 있어요.
- **휴대폰 맞춤**: 가로 폭 390px 기준이고, 아주 작은 폰과 가로 화면에서도 보기 편해요.
  카테고리 버튼은 스크롤해도 맨 위에 붙어 있고, `↑` 버튼으로 맨 위로 올라갈 수 있어요.

## 사용 방법

1. `index.html` 파일을 더블클릭해서 인터넷 창으로 열어요.
2. 손님에게 보여주려면 인터넷에 올린 주소(예: GitHub Pages)를 QR 코드로 만들어 테이블에 붙여요.

## 메뉴 고치는 방법

메뉴 정보는 `index.html` 맨 위의 **메뉴 정보 보관함**에 모여 있어요.
화면의 메뉴는 이 목록에서 자동으로 만들어지니, 다른 곳은 건드리지 않아도 돼요.
자세한 설명은 파일 안의 한국어 주석에도 있어요.

메뉴 한 줄은 이렇게 생겼어요.

```
{ 이름: "아메리카노", 가격: 4500, 설명: "산미가 적은 고소한 원두", 추천: "X", 품절: "X" },
```

| 하고 싶은 일 | 방법 |
|---|---|
| 가격 바꾸기 | `가격` 뒤의 숫자만 바꿔요. 쉼표나 `원`은 쓰지 않아요. (예: `5000`) |
| 이름·설명 바꾸기 | 큰따옴표 안의 글자만 바꿔요. |
| 메뉴 추가하기 | 같은 분류의 메뉴 한 줄을 통째로 복사해 바로 아래에 붙여넣고 내용만 바꿔요. 줄 끝 쉼표는 남겨요. |
| 메뉴 지우기 | 그 줄을 통째로 지워요. |
| 품절 켜기·끄기 | `품절: "X"`를 `품절: "O"`로 바꾸면 켜지고, 다시 `"X"`로 바꾸면 꺼져요. |
| 사장님 추천 켜기·끄기 | `추천: "X"`를 `추천: "O"`로 바꾸면 켜지고, 다시 `"X"`로 바꾸면 꺼져요. |
| 새 분류 만들기 | 분류 한 덩어리를 복사해 맨 아래에 붙이면 버튼도 자동으로 생겨요. |

알파벳 대문자 `O`를 써요. 숫자 `0`이 아니에요. 고친 뒤에는 저장하고 인터넷 창에서 새로고침(`F5`)하면 바뀐 내용이 보여요.
따옴표, 쉼표, 괄호가 하나라도 빠지면 메뉴가 안 보이니, 이상해지면 방금 고친 부분을 되돌려 보세요.

## 가게 정보(영업시간, 전화번호) 고치기

`index.html` 아래쪽 `영업시간` 부분을 찾아 글자를 고쳐요.
전화번호는 `href="tel:` 뒤의 숫자(하이픈 없이)와 버튼 글자 속 번호, 두 군데를 같이 고쳐야 해요.

## 디자인 바꾸기

색은 `index.html`의 `:root` 안에 있는 `#`으로 시작하는 색 번호를 고치면 바뀌어요.
현재 디자인은 플랫 벡터와 멤피스 스타일이고, 대표 색은 짙은 갈색(`#4A3728`)과 크림색(`#F5EFE6`)이에요.
이전 스팀펑크 디자인 코드도 파일에 남아 있어요. 새 디자인 구역을 지우면 돌아갈 수 있어요.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 메뉴판 전부(HTML, CSS, JavaScript)가 들어 있는 파일 |
| `CLAUDE.md` | Claude에게 알려주는 이 프로젝트의 작업 규칙 |
| `자료/기획시트.png` | 가게 정보와 메뉴를 정리한 기획시트 |
| `README.md` | 지금 보고 있는 설명 파일 |

## 사용한 기술

HTML, CSS, JavaScript만 사용했어요. 리액트 같은 별도 도구는 쓰지 않았어요.
글꼴은 고운 돋움을 먼저 쓰고, 없으면 맑은 고딕을 써요.
